📊 Scenario-Based 3-Statement Financial Model – Intel
📌 Overview
This project is a scenario-driven 3-statement financial model built for Intel, covering historical performance and forward-looking projections.
The model integrates the Income Statement, Balance Sheet, and Cash Flow Statement in a fully linked structure and allows flexible forecasting through Base, Bull, and Bear scenarios.
The primary goal of the project is to demonstrate financial modeling skills, scenario analysis logic, and cross-statement integration in a structured and professional format.

🧱 Model Structure
The Excel model is organized into the following sheets:
1. Introduction

Purpose and disclaimer of the model
Data sources and contact information

2. Historical Financials

Income Statement (2021–2025)
Balance Sheet (2021–2025)
Cash Flow Statement (2021–2025)
All data is sourced from publicly available Intel annual reports

3. Financial Model & Forecast (Core Sheet)

Historical + Forecast period (2021–2030)
Fully integrated 3-statement model
Includes:

Income Statement projections
Balance Sheet build-up
Cash Flow derivation


Balance Sheet Check ensures Assets = Liabilities + Equity across all periods
Dynamic calculations with interlinked formulas across all statements [Intel | Excel]

4. Scenario Assumptions

Centralized scenario input table
Supports:

Base case
Bull case
Bear case


Scenario selection dynamically feeds key assumptions into the model [Intel | Excel]


⚙️ Key Modeling Features
🔁 Fully Integrated 3-Statement Model

Net income flows into equity and cash flow
Cash flow output drives the cash balance in the balance sheet
Depreciation links PPE and cash flow
Working capital is modeled using operational drivers

📈 Scenario-Based Forecasting

Scenario selector (Base / Bull / Bear)
Revenue growth dynamically changes based on selected scenario
Forecast assumptions can be flexibly adjusted

🔑 Driver-Based Assumptions
The model uses fundamental financial drivers:

Revenue growth
Gross margin
SG&A (% of revenue)
R&D (% of revenue)
Working capital days:

Accounts receivable
Inventory
Accounts payable


Capex (% of revenue)
Depreciation (% of PPE)
Tax rate
Dividend payout ratio


🧮 Forecast Logic
Income Statement

Revenue grows based on scenario-driven assumptions
Costs and operating expenses modeled as % of revenue
EBIT, EBT, and Net Income calculated step-by-step

Balance Sheet

Working capital derived from operational ratios (days-based approach)
PPE driven by Capex and Depreciation
Equity evolves through retained earnings and financing flows

Cash Flow Statement

Indirect method
Includes:

Net income
Non-cash adjustments (D&A)
Working capital changes


Separate tracking of:

Operating (CFO)
Investing (CFI)
Financing (CFF)




✅ Model Integrity

Balance Sheet is checked for consistency in every period
All statements are dynamically linked
No hardcoded inconsistencies between statements
Forecast flows logically from assumptions to outputs
